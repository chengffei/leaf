Leaf 是什么？

Leaf 是免费开源的 Mac 电子书阅读器。双击 EPUB、MOBI 或 AZW3 文件即可阅读，关窗即退出。没有书库，不复制文件，不要账号。它记得你读到哪，读起来像 Kindle。原生 SwiftUI 应用，约 2.7 MB，需要 macOS 15。与 Amazon 无关。

常见问题

安装和使用中最常被问到的几件事。

怎么在 Mac 上打开 MOBI 和 AZW3 文件？

装好 Leaf 后，在访达里双击文件，或右键选「打开方式 › Leaf」。文件需要无 DRM。

Mac 上有像 Kindle 一样的电子书阅读器吗？

Leaf 用 Kindle 的方式读 Mac 上无 DRM 的 EPUB、MOBI、AZW3：按你的速度估算剩余时间、位置号、排版预设、脚注就地弹出、全书查找。高亮与笔记即将推出。没有商店，不用账号。

Leaf 和 Readest 有什么区别？

Readest 跨平台，有书库、同步、高亮和朗读。Leaf 只做 Mac，有意做得更少：没有书库，只记阅读位置，合上书就退出。约 2.7 MB，Readest 约 67 MB。

Leaf 免费吗？

免费，并以 MIT 协议开源。

为什么 macOS 提示无法验证开发者？

Leaf 没有经过 Apple 公证。先打开一次并关掉提示，再到「系统设置 › 隐私与安全性」点「仍要打开」。只需操作一次。

能打开在 Kindle 商店买的书吗？

只能打开无 DRM 的文件。Kindle 商店购买的书通常带 DRM，Leaf 打不开。

Leaf 是 Kindle 的 app 吗？

不是。Leaf 是独立的开源项目，与 Amazon 无关。它借鉴的是 Kindle 的阅读体验：排版、进度、查找，接下来是高亮与笔记，用来读 Mac 上无 DRM 的 EPUB、MOBI、AZW3。没有商店，不用账号。

Leaf 有书架或书库吗？

没有。Leaf 直接打开书所在的位置，不导入也不复制文件。Leaf 自己只记每本读到哪；和其他 Mac 文档应用一样，系统会在「文件 › 打开最近使用」里列出最近的文件。
