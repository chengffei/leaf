Leaf 是什麼？

Leaf 是免費開源的 Mac 電子書閱讀器。按兩下 EPUB、MOBI、AZW3、PDF、FB2 或 CBZ 檔案即可閱讀，關閉視窗就退出。沒有書庫，不複製檔案，不用帳號。它記得你讀到哪。原生 SwiftUI 應用程式，約 5 MB，需要 macOS 15。與 Amazon 無關。

常見問題

安裝與使用 Leaf 的常見問題。

怎麼在 Mac 上打開 MOBI 和 AZW3 檔案？

裝好 Leaf 後，在 Finder 裡按兩下檔案，或按右鍵選「打開檔案的應用程式 › Leaf」。檔案需要無 DRM。

Mac 上有簡單好用的電子書閱讀器嗎？

Leaf 能打開無 DRM 的 EPUB、MOBI、AZW3，以及 PDF、FB2、CBZ，一本書一個視窗。按你的閱讀速度估算剩餘時間，有位置號、排版預設、註腳就地彈出和全書尋找，能標示、寫筆記、加書籤並匯出。直排的書照原樣直排。關掉視窗就退出。沒有商店，不用帳號。

Leaf 和 Readest 有什麼不同？

Readest 跨平台，有書庫、同步和朗讀。Leaf 只做 Mac，刻意做得更少：沒有書庫，不同步，合上書就退出。閱讀位置、標示和書籤存在它自己的目錄裡，不碰書檔。約 5 MB，Readest 約 67 MB。

Leaf 免費嗎？

免費，並以 GPL-3.0 授權開源。

為什麼 macOS 說無法驗證開發者？

Leaf 沒有經過 Apple 公證。先打開一次並關掉提示，再到「系統設定 › 隱私權與安全性」按「強制打開」。只需操作一次。

能打開在 Kindle 商店買的書嗎？

只能打開無 DRM 的檔案。Kindle 商店購買的書通常有 DRM，Leaf 打不開。

Leaf 是 Kindle 的 app 嗎？

不是。Leaf 是獨立的開源專案，與 Amazon 無關。它用來在 Mac 上讀無 DRM 的 EPUB、MOBI、AZW3，沒有商店，不用帳號。

Leaf 有書架或書庫嗎？

沒有。Leaf 直接打開書所在的位置，不匯入也不複製檔案。Leaf 自己只記每本讀到哪；和其他 Mac 文件應用程式一樣，系統會在「檔案 › 打開最近使用過的」列出最近的檔案。
